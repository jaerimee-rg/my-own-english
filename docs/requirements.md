> 작성: 리듬체조 영어 학습 웹앱 프로젝트

## 1. 개요 (Overview)

리듬체조를 가르치는 선생님이, 수업에서 자주 쓰는 **영어 문장·단어를 저장·정리**하고,
저장한 자료로 **재미있게 학습**하며, **AI와 영어로 대화 연습**까지 할 수 있는 모바일 우선 웹앱.

- 리듬체조 도메인에 특화된 **나만의 영어 문장집 / 단어장**
- 플래시카드·퀴즈·이미지 연결·게임형 등 **다양한 학습 모드**
- 수업 상황을 상정한 **AI 자유 대화 연습**
- **앱 이름: My Own English**

### 1.1 핵심 가치
1. **모으기** — 수업에 꼭 필요한 표현을 손쉽게 저장
2. **익히기** — 반복 학습을 게임처럼 재미있게
3. **말하기** — AI와 실제 대화로 입에 붙이기

---

## 2. 목표 / 비목표

### 2.1 목표 (Goals)
- 리듬체조 수업 특화 영어 문장·단어를 빠르게 저장·분류·검색한다.
- 저장한 자료를 플래시카드·퀴즈·이미지 연결·게임형으로 학습한다.
- 발음(TTS)을 들으며 정확한 표현을 익힌다.
- AI 챗봇과 상황별 영어 대화를 연습한다.

### 2.2 비목표 (Non-Goals, v1 범위 밖)
- 다중 사용자(학생 계정), 진도·성적 관리 시스템
- 결제·구독 등 수익화 기능
- 일반 영어 문법 강의 / 토익·토플 등 시험 대비
- 학생 간 소셜·랭킹 기능

---

## 3. 사용자 (Users)

- **단일 사용자: 선생님(본인) 전용**
- 아이들은 직접 로그인하지 않음 (선생님이 수업 중 보여주며 활용)
- 인증은 **간단한 단일 계정 로그인**으로 충분 (Supabase Auth, 이메일/비밀번호 또는 매직링크)

---

## 4. 핵심 기능 (Features)

### 4.1 문장·단어 저장 (Phrasebook)
- **항목 구성**
  - 영어 문장(필수)
  - 한국어 뜻(필수)
  - 발음/메모(선택)
  - 분류 정보(아래 4.1.1)
- **입력 방식 (두 가지 모두 지원)**
  1. **직접 타이핑** — 영어 문장 + 한국어 뜻 직접 입력 (기본)
  2. **AI 제안** — 한국어로 하고 싶은 말을 적으면 AI가 자연스러운 영어 문장(+예시/뉘앙스)을 제안 → 선생님이 선택·수정 후 저장
- 목록 검색·필터·정렬, 수정·삭제, 즐겨찾기/북마크

#### 4.1.1 분류 체계 (4가지 축 동시 지원)
| 축 | 예시 |
|---|---|
| **소도구별** | 리본(Ribbon), 후프(Hoop), 공(Ball), 곤봉(Clubs), 줄(Rope), 맨손(Floor) |
| **수업 상황별** | 인사, 워밍업, 동작 지시, 칭찬, 교정, 정리/마무리 |
| **난이도/레벨별** | 초급 / 중급 / 고급 |
| **자유 태그** | 선생님이 자유롭게 부여하는 태그 |

> 한 문장에 여러 축의 값을 부여할 수 있음 (예: 소도구=리본, 상황=동작 지시, 난이도=초급, 태그=#회전).

### 4.2 학습 모드 (Study) — 모두 포함
1. **플래시카드** — 앞면 영어 / 뒷면 한국어(또는 반대), 넘기며 암기, 발음 듣기 버튼
2. **퀴즈**
   - 객관식: 뜻 맞추기 / 영어 맞추기
   - 빈칸 채우기: 문장 일부를 비워두고 입력
3. **이미지/그림 연결** — 리듬체조 동작·소도구 이미지와 영어 표현 매칭
4. **게임형** — 정답 시 점수·뱃지·캐릭터 보상으로 동기부여
5. 학습 범위는 분류(소도구/상황/난이도/태그) 기준으로 선택 가능

### 4.3 AI 대화 연습 (Conversation Practice)
- **AI 챗봇과 자유 대화** (Claude API 기반)
- **상황 선택형** 시나리오 + 자유 대화 모두 지원
  - 모드 A: AI가 **학생(아이) 역할** → 선생님이 가르치는 상황 롤플레이
  - 모드 B: AI가 **연습 상대/튜터** → 선생님 본인 영어 표현 연습 + 피드백
  - 상황 예시: 인사, 동작 지도, 칭찬, 교정, 수업 마무리 등에서 선택
- 저장된 문장·단어를 대화 맥락에 활용 (해당 표현 위주로 연습)
- 대화 중 표현 교정·대안 제안, (선택) 대화 기록 저장

### 4.4 발음 듣기 (TTS)
- 문장·단어를 원어민 발음으로 재생
- 플래시카드·퀴즈·문장 상세 등 전역에서 재생 버튼 제공
- v1: 브라우저 Web Speech API(SpeechSynthesis) 우선 → 품질 필요 시 외부 TTS 검토

## 5. 비기능 요구사항 (Non-Functional)

- **플랫폼**: 모바일 우선(휴대폰/태블릿) 반응형 웹앱, PWA(홈 화면 추가) 고려
- **성능**: 첫 화면 로딩 빠르게, 학습 화면 즉각 반응
- **언어**: UI 한국어 / 학습 콘텐츠 영어+한국어
- **오프라인**: v1은 온라인 전제 (추후 PWA 캐싱 고려)
- **보안**: 단일 계정 인증, 본인 데이터만 접근 (Supabase RLS)
- **비용 관리**: AI(문장 제안·대화)는 LLM 호출 비용 발생 → 호출 빈도/길이 합리적으로 제한

## 6. 기술 스택 (Tech Stack)

| 영역 | 선택 |
|---|---|
| 프론트엔드 | **Next.js** (App Router) + TypeScript |
| 스타일링 | Tailwind CSS (모바일 우선) |
| DB / 인증 / 스토리지 | **Supabase** (Postgres + Auth + Storage, RLS) |
| AI 대화·문장 제안 | **Claude API** (claude-sonnet-4-6 기본, 필요 시 opus) |
| TTS | 브라우저 Web Speech API (v1) |
| 배포 | **Vercel** |

## 7. 데이터 모델 (초안)

> 상세 스키마는 설계 단계에서 확정. 아래는 개념 모델.

- **phrases** — id, user_id, english, korean, note, apparatus, situation, level, is_favorite, created_at
- **tags** — id, user_id, name
- **phrase_tags** — phrase_id, tag_id (N:N)
- **images** — id, user_id, phrase_id(nullable), url, caption (이미지 연결 학습용)
- **study_progress** — id, user_id, phrase_id, mode, score, streak, last_studied_at (게임/점수용)
- **conversations** — id, user_id, scenario, created_at
- **conversation_messages** — id, conversation_id, role, content, created_at

## 8. 화면 구성 (Information Architecture)

1. **홈 / 대시보드** — 오늘의 학습, 빠른 진입, 최근 추가 문장
2. **문장집(Phrasebook)** — 목록·검색·필터, 추가/수정(직접 입력 + AI 제안)
3. **학습(Study)** — 모드 선택(플래시카드/퀴즈/이미지/게임) → 범위 선택 → 진행
4. **대화 연습(Conversation)** — 상황 선택 또는 자유 대화 → AI 챗
5. **설정** — 계정, 표시 옵션, 데이터 관리

---

## 9. 개발 우선순위 / 단계

**v1은 핵심 기능 모두 포함**하되, 아래 순서로 구축 권장:

- **Phase 1 — 기반 + 문장집**: 프로젝트 셋업, 인증, 문장 CRUD/분류/검색, TTS
- **Phase 2 — 학습 모드**: 플래시카드 → 퀴즈 → 이미지 연결 → 게임형(점수·뱃지)
- **Phase 3 — AI**: 문장 AI 제안, AI 대화 연습(상황 선택형 + 자유 대화)
- **Phase 4 — 다듬기**: 모바일 UX, PWA, 디자인·애니메이션, 비용 최적화
